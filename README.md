##  Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Abhicodes001/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Production build**:
   ```bash
   npm run build
   ```
